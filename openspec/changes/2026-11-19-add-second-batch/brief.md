## 画面要求（「惊艳」基准）

- 水墨淡彩：宣纸底、笔墨晕染。实物（picture 层）要让孩子一眼认出、想伸手摸；每个字形变形都要有戏；finale 收尾要呼应实物。
- 异步动画只用 `src/util.js` 的 `tween/wait({check})`；禁用 `setTimeout` 和 CSS transition 控流程。
- 滤镜用现成 `#ink` `#wash1` `#wash2` `#glow`；新建滤镜/渐变 id 加 `<id>-` 前缀；小元素慎用 wash2（SOP 2.5）。

## 台词要求（`data/chars/<id>.json` 的 lines）

- 键：`intro`、`sound`、每个字形一条（键 = form id）、`order`、`trace`、`retry`、`done`。`order` 写「{char}，是这样写的：{笔画名逐个}。」
- 3-8 岁口语短句；**不出现英文字母和数字**；每句 ≤ 50 字。
- **多音字**（一）的 `sound` 用能锁定读音的词：「一。一个的一。」；同音家族成员（情，与青清晴同音）也用词锁定：「情。心情的情。」其余单音字写「{char}。」。

## 十个字的任务卡

端口分配（serve 与 playwright 都用它）：见各自的字——批一 yi=4211、da=4212、tian=4213、cong=4214、bi=4215；批二 bei=4217、zhong=4218、huo=4219、xin=4220、qingxin=4221。

### 一（id: yi，1 画）
- 最简单也最要紧的字：一横。它后面要组进「天」。
- 字形路线：只有楷书一笔（forms=[kaishu]，红线允许；甲骨文本就是一横，不必单列）。
- picture 建议：有分量的横置实物（挑着两只水桶的扁担／铺在小溪上的独木桥），**忌**做成横贯画面的灰线（审美红线 2.1 的教训）；写完后实物变成「一」要有戏。
- 台词不讲「太初哲学」，只讲「一横就是一个」。多音字 sound：「一。一个的一。」

### 大（id: da，3 画）
- 构成/比较：**已学「人」是侧着站，大是正面张开手臂**——这是人形族比较环节必点的一步（画面或旁白都要能对上）。
- 字形路线：甲骨文（正面人形，臂腿张开）→ 小篆 → 楷书。
- picture 建议：小朋友张开手臂量一棵大树/抱一个大西瓜，「这么大！」。meaning：大山。

### 天（id: tian，4 画）
- 构成：**大 ＋ 一 → 天**（组字是重头戏：刚学的「大」头顶上落下一横）。说文「颠也」（头顶）→ 天。
- 字形路线：组字（大上添一横）→ 楷书；小篆可选（拓片核对后决定）。
- picture 建议：仰头看天的小朋友、头顶高远的天空。

### 从（id: cong，4 画）
- 构成：**人 ＋ 人 → 从**，一前一后相随（说文「相听也」——听从、跟随）。
- 字形路线：甲骨文（两人前后）→ 小篆 → 楷书。
- picture 建议：大人牵着孩子走路/小鸭子排队跟着鸭妈妈。meaning：跟从、从前。
- 比较铺垫：与「比」的并肩做对照（本字先出，「比」课里再呼应）。

### 比（id: bi，4 画）
- 构成：**人 ＋ 人 → 比**，肩并肩同向。**比较环节必点**：「从是前后跟着，比是肩并肩」。
- 字形路线：甲骨文（两人并肩）→ 小篆 → 楷书。
- picture 建议：两个孩子肩并肩比身高。meaning：比一比、比赛。
- ⚠️ 形近提醒：比与北楷书形近——本课只讲「比是并肩」，北的相背留给北课呼应，不抢戏。

### 北（id: bei，5 画）【需特有测试：相背交互至少 1 条】
- 构成：**人 ＋ 人 → 北**，背对背（说文「乖也，相背」）。字形讲相背，现代义（北风、北边）照常用，不展开「背」的引申。
- 字形路线：甲骨文（两人相背）→ 小篆 → 楷书。
- picture 建议：两个背对背生气/各看一边的小人，一人朝暖色、一人朝冷色。
- 特有测试：覆盖「两人转成相背」的交互或形态断言（参照 ren.spec.js 的形态锁定思路）。

### 众（id: zhong，6 画）【需特有测试：三人叠加动线至少 1 条】
- 构成：**人 → 从同款叠加 → 众**，三个人站在一起（说文㐺「众立也，从三人」）。**呼应 木→林→森 的叠加母题**（比较环节点出「树有林森，人也有从众」级别的呼应，台词口语化）。
- 字形路线：一人 → 两人 → 三人成字 → 楷书（叠加演示可用组字形态；不画眾的日下三人历史形，不把简化形讲成古字源）。
- picture 建议：操场上好多好多人（观众席/放学的人群）。
- 特有测试：覆盖叠加动线（forms 顺序/印章）或三人形态断言。

### 火（id: huo，4 画）
- 象形：火苗。字形路线：甲骨文（主焰＋火星点，笔数以拓片为准）→ 小篆 → 楷书。
- picture 建议：夜晚篝火/一支蜡烛，火苗会呼吸。**定火族色系**（与日系朱砂拉开层次，如绛红＋焰心暖黄），定完回写 etymology.md 色系表。
- meaning：火苗、火车。小火星是小元素——慎用 wash2（SOP 2.5），用 `#ink` 或自建轻滤镜。

### 心（id: xin，4 画）
- 象形：心脏。字形路线：甲骨文（心廓＋内点，以拓片为准）→ 小篆 → 楷书（卧钩加三点，可讲「三点像怦怦跳」——是形态明喻，不作字源断言）。
- picture 建议：把手放胸口感受心跳（呼吸/脉动节奏）。定心族色系，回写 etymology.md。
- meaning：心情、开心。心是下一字「情」的部件，结尾可埋一句「心还能组成别的字哦」级别的钩子（不剧透）。

### 情（id: qingxin，11 画）【需特有测试：组字交互至少 1 条】
- 构成：**忄(心) ＋ 青 → 情**，形声，青表音。**声旁家族点题**：「情里也藏着青，和清、晴是一家人」；忄 是刚学的「心」站到旁边（比较环节点出）。
- 字形路线：组字（忄＋青）→ 楷书（沿用清/晴先例，不画古文字）。
- picture 建议：小孩捧着心想着喜欢的人/事（想念、心情）。
- sound 用词锁定同音：「情。心情的情。」meaning：心情。
- 特有测试：覆盖组字交互（参照 qingshui.spec.js）。
