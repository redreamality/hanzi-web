## 四、etymology 行改动摘要

- 「情」行：待核 → ✅。核对汉典（2026-11-20 抓取）：说文「人之陰气有欲者。从心青聲。疾盈切」（页面说文段引「有欲者也」，者/者也微异，不进台词）；读音 qíng（zdic 音频交叉核对）；拓片 swxz/60C5 + xiaozhuan/27_60C5 列密度均确认左右结构左心右青，「从心青声」确证。沿用清/晴先例不画古文字。
- 色系表：心族行已被并行「心」课 agent 回写（胭脂红系 #c2455c/#8e2f4a/#f2c1bd）；我未重复改写该行，改为把本课实际用色**对齐**族色（kid 的心 fill/描边/晕、morph 的 ROSE 一律改用 #c2455c/#8e2f4a/#f2c1bd，像素采样精确命中）。

## 五、台词与机制对照

- sound：「情。心情的情。」（同音词锁定，青清晴情同音）✓
- zu：「心里的这颗心，轻轻飘起来，站到青的旁边，变瘦变窄，成了竖心旁。心和青在一起，就是情。」——「心站到旁边」比较环节（心刚学过）✓；形态描述不作字源断言 ✓
- kaishu：「情里也藏着青，和清、晴是一家人，读音都像青。」——声旁家族点题 ✓（hanzi-network 家族聚簇）
- 全部台词无英文字母、无数字、每句 ≤50 字、口语 ✓；音频与台词一一对应 ✓

## 六、拿不准的点

1. **「变瘦变窄，成了竖心旁」的讲法**：忄即心作偏旁（《说文》情字段注「从心。靑聲」），「心站到旁边变成竖心旁」是部件形态描述，非字源演绎；但「竖心旁」这个名称本身是后世习惯叫法，台词里当作称呼使用（未断言「古人把心写窄」之类）。自认合规，留终审。
2. **忄组字形态的舒展幅度**：组字时两个点放大 1.3 倍、竖 1.04（「心舒展着」的形态隐喻），楷书收正。舒展幅度是审美选择，无考据依据也无考据风险；幅度是否合适留终审。
3. **done 场景心与字迹重叠**：孩子淡影 0.3 在写字层之下，心 (512,596) 位置被青撇笔覆盖（采样为墨色）。这是引擎层级（picture 在 kaishu/trace 之下）的固有表现，与清/晴 done 场景一致，非缺陷；若终审觉得心被字挡住可惜，可把 finale 的心落点下移。
4. **拓片列密度分析**只做了定量（左右结构）没做逐笔画比对——因为本课不画古文字，拓片仅佐证「从心青声」的结构；若后续要画小篆，refs/qingxin/ 已留档。
5. **并行负载下 11 笔的「按笔顺描对」测试**在满载时逼近 60s 超时（本批最多笔画字）；无干扰时 35-45s 通过。这是测试时长与机器负载的问题，非本课缺陷；若主会话全量门禁遇满载超时，重跑即可。
