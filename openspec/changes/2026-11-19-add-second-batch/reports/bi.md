## 4. etymology 行改动摘要

`etymology.md`「比」行（只用 Edit 改本行）：待核 → **✅**。
- 说文原文更正：预填「密也。二人为比」不准；汉典·说文解字·卷八·比部实为「**密也。二人爲从，反从爲比。凡比之屬皆从比。夶，古文比**」，已照录（「反从为比」未进台词——三到八岁讲不了「反从」，台词只讲并肩，与任务卡一致）。
- 字形依据补已核来源：甲骨文 zy/jiaguwen/42_F609、F60A（两人侧立并肩同向、面朝左）；说文小篆拓片 swxz/6BD4（两人紧挨并列、四条通长竖线、底部向左下微撇）。
- 画法/讲法落定：两个孩子肩并肩比身高 → 甲骨文 → 小篆 → 楷书，四笔对应（左人身臂→竖提、左人腿→横、右人腿→撇、右人身臂→竖弯钩）；比较环节必点「从是前后跟着，比是肩并肩」；不提北。

## 5. 拿不准的点（明说）

1. **甲骨文细部简化**：拓片 F609/F60A 的手臂有掌形分叉、身与臂分离等细部，我沿用已过审的「人」课单人形（头身垂臂一笔＋腿一笔）×2 并列——整体结构（两人并肩同向、四线并列、两人紧挨）与拓片一致，细部做了人形族的统一简化。若用户要求逐拓片还原细部，需返修。
2. **sound 用词锁定**：比教学读音只有 bǐ（单音），但汉典录有旧读 bì/pí（如「皋比」），故按多音字规则用「比。比一比的比。」锁定，兼防 TTS 读错。
3. **小篆腿底撇向**：swxz/6BD4 拓片四线底部均向**左下**微撇（「人」课拓片 4EBA 的腿向右下撇），各按各拓片画，两课不一致是拓片使然，不是笔误。
4. **finale 位置贴近钩尾**：重现的两个孩子占 x 360-550，右缘距竖弯钩底部弯（x 553 起）只有约 4px；像素采样确认各自独立（孩子 lum 31、钩底 lum 30 分属两点），但视觉上是贴着站的——「肩并肩贴着字」是有意设计，若嫌挤可把 scale 从 0.34 再调小。
5. **任务卡的「比较环节必点」**放在 kaishu 台词里（「从是一前一后跟着走，比是肩并肩」），画面上未再叠加「从」字对照——「从」课由并行 agent 同批在做，跨课画面引用未做（拿不准从课的最终形态，避免耦合）。
