# 字形审计：其余 11 字 —— 代码甲骨文形 vs 汉典拓片（2026-11-20 第二阶段）

承接 `audit-ri-yue-mu.md`（日/月/木）。本篇覆盖 ren 人、ming 明、lin 林、sen 森、xiu 休、da 大、cong 从、bi 比、bei 北、huo 火、xin 心。

## 方法（第二阶段新增）

- 拓片：抓自汉典（同既证配方），存 `../refs/<id>/`，每字 2~5 件甲骨＋说文小篆（个别另有金文/异形篆）。
- **代码形零重画**：`../refs/audit2-raster.mjs` 在浏览器里直接 `import` 各字 `src/chars/<id>/morph.js`，调 `createMorph().reset()` 用**各字自己的渲染代码**输出 oracle 形（huo 的 reset 渲染 flame，特例改用其 `forms.js` 导出的 ORACLE+ribbon）。序列化 SVG → canvas → 与拓片同规格 256 二值位图。
- 度量：`../refs/audit2-measure.mjs`（连通域布局、域间相对位置/高差/间隙、顶部墨位）；剪影速览 `../refs/audit2-view.mjs`。
- 口径：frac 相对全图 bbox；gap 为两域水平间隙/全宽（-0.99/-1 为域序颠倒时的无效哨兵，实际间隙另算）；headX 为域顶部 18% 墨中心的 x frac（判人形前倾方向：偏右=面向左）。

### bi 比 —— 可选微调
