## 4. etymology 行改动摘要

`etymology.md`「北」行（只用 Edit 改本行）：待核 → **✅**。
- 说文原文核对：汉典·说文解字·卷八·北部「**乖也。从二人相背。凡北之屬皆从北。博墨切**」——预填一致，补全后半句。
- 字形依据补已核来源：甲骨文 zy/jiaguwen/42_F60B～F60F（两人镜像相背：左人朝左右人朝右，各=头顶＋内侧长竖＋向下外甩的短弧）；金文 33_E0BB（手臂已横伸向外，与楷书横/撇位置直接衔接）；说文小篆 swxz/5317、zy/xiaozhuan/27_5317（每人头顶横杠＋两条通长竖线、外线底端外撇、右人右下小尾=竖弯钩扫笔之祖）。拓片已存 `refs/bei/`。
- 画法/讲法落定：两个背对背生气的小朋友（一冷一暖）→ 甲骨文 → 小篆 → 楷书；五笔对应（左人竖=头身、横=左臂、提=左腿；右人撇=右臂、竖弯钩=头身＋向右扫出的腿）；比较环节点全「从是一前一后，比是肩并肩，北是背对背」；bèi 旧读不进台词，sound 用「北。北风的北。」锁定 běi。

## 5. 拿不准的点（明说）

1. **甲骨文细部沿用人形族简化**：拓片 F60B～F60F 的手臂有掌形分叉、身线与臂线起讫各有出入，我沿用已过审的「人」课两笔人形（头身垂臂＋腿）×2 镜像，另把左人腿画成底端外撇的短提笔（拓片内线底端确有外撇）。整体结构（镜像、相背、中缝分明、手臂外甩）与拓片一致；逐拓片还原细部需返修。
2. **小篆五笔对四线的取舍**：说文小篆每人只有「头横＋两条竖线」，而楷书左人是三笔。我把左外线给横（手臂化进竖线）、提叠在外线下段（小腿），渲染上重叠为同一条线，变形连续无跳变；这是结构取舍不是拓片原文，若审校认为应改由提承担整条外线、横并入头横，需重调 SEAL 锚点。
3. **picture 的冷月与风缕偏淡**（lum 217/219，纸面 222）：有意克制（远山淡月，不抢两个小人），冷山（193）和暖日（214）对比明显。若终审觉得冷侧存在感不够，可把冷月 opacity 从 0.32 提到 0.45 左右。
4. **done 里收尾小朋友较小**（scale 0.22，字底空档 x340-520 y840-1010）：北字五笔铺满底部左右，中间空档比「比」窄，小朋友缩得比 bi（0.34）小；像素确认两人俱在（lum 32）。嫌小可微调 scale，但再大就会碰竖的收笔和竖弯钩的扫笔。
5. **比较环节三连句**放在 kaishu 台词（「从是一前一后，比是肩并肩，北是背对背」）：跨课画面引用未做（同批并行课的最终形态不确定，避免耦合），与 bi 的处理一致。
