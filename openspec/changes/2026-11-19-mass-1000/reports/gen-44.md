# 第 44 批通用课生成报告（gen-44）

- 范围：plan-1000.json 非定制字序第 431-440，共 10 字，stage 10。
- 证据源：全部取自 `data/sources/plan-extras.json` 各 id 条目（pinyin 原样抄录；说文条目见各节）。
- 同音锁定依据（plan 内序号小于本字的完全同音字）：越=月(yuè)、器=气(qì)、须=需(xū)、研=言(yán)；称因多音（对称 chèn）锁定。九/究/容/照/写无完全同音，sound 用默认短读。

## yue4 越

- meaning：越过｜words：越过、越来越
- kaishu：「越，左边是走字旁，跑起来使劲一迈，一下就越过了小水沟。」
- 目的 3 层：字理（说文「度也。从走戉聲」——只取意符「从走」= 跑过、跨过；声旁戉未学，不提）。
- 拿不准：无。「走字旁」是对现代字形的描述，意符含义可追溯到「从走」。

## qi4b 器

- meaning：机器｜words：机器、电器、乐器
- kaishu：「器，四张小口围着一只小狗，小狗帮人们看守东西，看得可认真啦。」
- 目的 3 层：字理（说文「皿也。象器之口，犬所以守之」——四口+犬看守，直白可懂，忠实转写）。
- 拿不准：「四张小口」是对现代字形的白描（口非 recent 部件，未用「刚学过」构成句式）。

## rong2 容

- meaning：笑容｜words：笑容、容易、宽容
- kaishu：「容，宝盖头像屋子，下面是山谷的谷，屋子山谷都装得下，装得下就是容。」
- 目的 3 层：字理（说文「盛也。从宀、谷」——宀谷会意，屋子山谷都能容纳）。
- 拿不准：宀、谷均非 recent 部件（partInfo 为空），此句是说文「从宀谷」的转述，不是「刚学过」构成句式；「宀像屋子」是通行讲法。未提声旁（extras 本条无「声」公式，不敢写「谷声」）。

## zhao4 照

- meaning：照相｜words：照相、照片、照顾
- kaishu：「照，上面有个小太阳，下面四点火苗，都亮亮的，把黑黑的角落照得亮堂堂。」
- 目的 3 层：字理（说文「明也。从火昭聲」——只取意符火=亮；声旁昭未学，不提）。
- 拿不准：「四点火苗=灬是火」依据「从火」及灬由火隶变的通行事实，属字理层而非构成层（火不在 partInfo）；「小太阳」是明喻（日未点名为部件）。

## xu1b 须

- meaning：胡须｜words：胡须、必须
- kaishu：「须，左边几撇像毛毛，很久以前人们说，须就是人脸上长的胡须。」
- 目的 3 层：字理（说文 via 須「面毛也。从頁从彡」——只取「面毛」含义+彡的毛形明喻；頁=人头一层太深，不讲）。
- 拿不准：head 为繁体「須」，台词只描述现代字形「须」，无繁形描述。

## jiu3 九

- meaning：九个｜words：九个、十九
- kaishu：「九，先写一撇，再写一笔弯弯钩，像小尾巴轻轻翘起来。」
- 目的 3 层：朴素（说文「陽之變也。象其屈曲究盡之形」对孩子不可懂，主动降级为白描+明喻，不写字理）。
- 拿不准：无。order 为两画逐笔名「撇，横折弯钩」，与 strokes.json 两笔走向吻合。

## jiu1 究

- meaning：研究｜words：研究
- kaishu：「究，下面藏着刚学过的九，读音跟九很像，研究就是问呀问，问到明白才罢休。」
- 目的 3 层：构成 + 声旁（九 recent:true；说文「窮也。从穴九聲」——九既是部件又是声旁，读音点题有据）。
- 拿不准：穴字头未提（穴非 recent）；「问呀问问到明白」是对「窮也」（穷尽）的温和转写，未展开洞穴意象。

## yan2b 研

- meaning：研究｜words：研究、钻研
- kaishu：「研，左边是刚学过的石，把东西放在石头上磨，磨得又细又慢才叫研。」
- 目的 3 层：构成 + 字理（石 recent:true；说文「䃺也。从石幵聲」——取意符石=研磨，义为细磨）。
- 拿不准：声旁是「幵」不是「开」（右边开为 non-recent 且与幵不同源），为避免把简化字形讲成古字源，未做声旁点题。开未提。

## xie3 写

- meaning：写字｜words：写字、写信
- kaishu：「写，头上像戴顶小帽子，下面弯弯一笔勾，提起笔来写字，它天天陪着你。」
- 目的 3 层：朴素（说文 via 寫「置物也」与书写义之间引申链太长，孩子不可懂，降级；与 non-recent 不点；简体右边「与」并非繁体声旁「舄」，不做声旁讲解）。
- 拿不准：无。order 为五画逐笔名「点，横钩，横，竖折折钩，横」，与 strokes.json 五笔走向吻合。

## cheng1 称

- meaning：称一称｜words：称赞、称呼、称一称
- kaishu：「称，很久以前人们用它称一称稻谷有多重，称完心里就有数啦。」
- 目的 3 层：字理（说文 via 稱「銓也。从禾爯聲……」长文讲称量禾谷——取「称禾谷之重」这一可懂主干；声旁爯未学，禾、尔均不在 recent，不点构成）。
- 拿不准：head 为繁体「稱」，台词只描述现代用法与字形无关；「稻谷」是「禾」的孩子语转写。
