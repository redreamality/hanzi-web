## 逐字

### dong1 东（dōng）
- meaning：东西；words：东西、东边
- kaishu：「很久以前，人们说太阳从树里升起，那一边就是东。」
- 目的 3 层：字理（說文 via 東「動也。从木。官溥說：从日在木中」→ 只取官溥说「日在木中」的白话；「人们说」对应转述性质，不断言简体字形里有日有木）
- 拿不准：无。东为简化字形，「树里升太阳」只作字的家系故事讲，未描述现代字形

### sheng1b 声（shēng）
- meaning：声音；words：声音、大声
- kaishu：「很久以前，声字里有一只耳朵，告诉我们声音要用耳朵听。」
- 目的 3 层：字理（說文 via 聲「音也。从耳殸聲」→ 只取「从耳」；简体声里已无耳，用「很久以前」限定讲家系）
- 拿不准：同音已学 生，sound 用「声音的声」锁定；**partInfo 标 士 recent:true，但 士（shi4f）实际 order 序 384，在本字（202）之后未学——构成台词未提 士**；殸（磬）声一层因殸非已学字、简体字形不显，不写

### ti2 提（tí）
- meaning：提水；words：提水、提包
- kaishu：「提，提东西要用手，右边藏着是，读音和是有点像。」
- 目的 3 层：声旁（說文 direct「挈也。从手是聲」→ 是 已学、序 22、在 partInfo 里对上；tí 与 shì 韵母同为 i，写「有点像」不作「一模一样」断言）；「提东西要用手」是「从手」的一笔带过，未单独展开字理层
- 拿不准：是 非 recent（差 181），故构成层不说「刚学过的是」，声旁点题不受 recent 限制

### ji2 及（jí）
- meaning：来得及；words：来得及、来不及、及格
- kaishu：「很久以前，人们画一只小手，去够前面的人，追上了就是及。」
- 目的 3 层：字理（說文 direct「逮也。从又从人」→ 又是手、逮是追上，逐项对得上；独体字无构成层）
- 拿不准：无

### jie3 解（jiě）
- meaning：解开；words：解开、解扣子
- kaishu：「解，左边像一只牛角，右边藏着小刀和牛，用刀分开牛角就是解。」
- 目的 3 层：字理（說文 direct「判也。从刀判牛角」→ 角、刀、牛在现代字形里都真实可见：左角、右上刀、右下牛；「像／藏着」为形态描述，不点未学的部件字名）
- 拿不准：多音字（jiě/jiè/xiè），sound 用「解开的解」锁定；**partInfo 标 角 recent:true，但 角（jiao3）实际 order 序 737，在本字（205）之后未学——不写「刚学过的角」**，牛角／小刀只作为孩子认识的事物出现在字理故事里

### shui3 水（shuǐ）
- meaning：喝水；words：喝水、水果
- kaishu：「水，很久以前人们画流水，中间一条大河，两边溅起小水花。」
- 目的 3 层：字理（說文 direct「象眾水並流」→ 象形描述；现代字形中竖居中、两侧撇捺，与「中流两侧水花」对得上）
- 拿不准：无。水是独体象形字，无构成与声旁层

### ming2 名（míng）
- meaning：名字；words：名字、写名字
- kaishu：「很久以前，天黑了看不清脸，人们开口说出自己的名字。」
- 目的 3 层：字理（說文 direct「自命也。从口从夕。夕者，冥也。冥不相見，故以口自名」→ 天黑（夕）看不见所以开口（口）报名，逐项有据）
- 拿不准：同音已学 明（bespoke，míng），sound 用「名字的名」锁定；夕、口 均未学且 decomp 为空，构成层不点

### zhen1 真（zhēn）
- meaning：真的；words：真的、认真
- kaishu：「真，一横一竖打头，下面笔画挨得紧，站得端端正正。」
- 目的 3 层：朴素（說文 via 眞「僊人變形而登天也」为仙人升天之说，对三到八岁难懂且与简化字形无涉，按「拿不准不写」放弃字理；具 虽标 recent:true 但实际 order 序 404 在本字 208 之后未学，十 非 recent，构成层不点）
- 拿不准：**具 的 recent 标记与真实顺序矛盾（同 gen-14 的占／王 先例）**；「一横一竖打头」避开了「十字头」的部件点名

### lun4 论（lùn）
- meaning：讨论；words：讨论、议论
- kaishu：「论，和说话有关，大家你一句我一句地商量，就是讨论。」
- 目的 3 层：字理（說文 via 論「議也。从言侖聲」→ 只取「从言」表义与「議也」互训；言字旁之名未点，因 言 未学，用「和说话有关」替代）
- 拿不准：多音字（lùn/lún），sound 用「讨论的论」锁定；声旁 仑（lún）不在字表已学范围（families 为 null、partInfo 无），声旁层不写

### chu4 处（chù）
- meaning：到处；words：到处、好处
- kaishu：「很久以前，人们走累了，走到小桌子旁边停下来歇脚，这就是处。」
- 目的 3 层：字理（說文 via 処「止也。得几而止。从几从夂」→ 几是矮桌、夂是走到，走到几旁停下即「止也」，逐项有据；简体处已无几形，用「很久以前」限定讲家系）
- 拿不准：多音字（chù/chǔ），sound 用「到处的处」锁定；几、夂 均未学，构成层不点
