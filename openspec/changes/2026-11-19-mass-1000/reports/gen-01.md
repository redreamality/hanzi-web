# gen-01 批次报告（第 1 批，order 中前 10 个非定制字）

字：的 de、是 shi4、不 bu4、了 le、在 zai4、有 you3、我 wo3、这 zhe4、个 ge4、们 men（order index 21-30）。

本批特点：10 个全是高频虚词/代词，多数无「看得见摸得着」的实物义，meaning 全部选孩子天天挂在嘴边的口语词。声旁层 0 次：本批声旁字（勺、才、又、文、门）在孩子学到本批字时均未学，全部按「宁可少说」放弃。

## de 的

- meaning：我的（words：我的/你的/他的）
- kaishu：「的，左边方方的，右边像把小勺子，要念得又轻又短。」
- 目的 3 层：朴素白描（「像小勺子」为视觉明喻，不点部件）。
- 拿不准：partInfo 标「白 recent:true」，但白在 order 309 序、「的」在 21 序——孩子此时未学白，点「里有刚学过的白」与学序事实矛盾，故未点构成。recent 标记与学序的矛盾建议编排方核对（们的「门」同此问题）。
- sound 用锁定式「的，我的的。」（de/dí/dì 多音）。

## shi4 是

- meaning：是的（words：是的/就是）
- kaishu：「是，里面有刚学过的日。太阳正正地照着，是，就是对！」
- 目的 3 层：构成（日，index 0，真实刚学）＋ 字理（说文「直也。从日、正」白话转写）。
- 拿不准：字理句把「从日、正」与训释「直也」合并为「太阳正正地照着」，转写程度请校对把关。

## bu4 不

- meaning：不要（words：不要/不用/不行）
- kaishu：「很久以前，人们画一只小鸟朝天上飞，一横就是天，飞走了不回来，这就是不。」
- 目的 3 层：字理（说文「鳥飛上翔不下來也。从一，一猶天也」，用「很久以前，人们画」转述框架）。现代古文字学对「不」另有花萼诸说，此处严格按说文第一依据。
- 拿不准：无。

## le 了

- meaning：好了（words：好了/来了/走了）
- kaishu：「了，人们说它是『子』字收起了小胳膊，你看像不像？」
- 目的 3 层：字理（说文「尦也。从子無臂」，转写为「子收起小胳膊」；子未学故不点构成，仅作字形故事）。
- sound 用锁定式「了，好了的了。」（le/liǎo 多音）。
- 拿不准：子的弯钩与了的竖钩形微异，「收起小胳膊」只述横笔之去，请校对把关措辞。

## zai4 在

- meaning：在家（words：在家/现在/正在）
- kaishu：「在，上面一横一撇，下面方方正正，像一小块平地，稳稳当当。」
- 目的 3 层：朴素白描（「像一小块平地」是视觉明喻，与说文「从土」暗合但未点「土」部件）。
- 拿不准：说文「存也。从土才聲」——土、才均未学（partInfo 空），声旁不点；「存也」无画面，字理不写。

## you3 有

- meaning：都有（words：都有/没有/还有）
- kaishu：「有，像一只小手，捧着一块小圆饼，好东西都在手心里。」
- 目的 3 层：朴素白描＋视觉明喻（小手＝又、圆物＝月，与说文「从月又声」暗合）。
- 拿不准：月虽是第 2 个学的字，但 partInfo 未列月，按规矩未点构成；说文「不宜有也」无法转成孩子语言，字理不写。明喻是否被视为变相点部件，请校对定夺。

## wo3 我

- meaning：我们（words：我们/我的/我家）
- kaishu：「我，笔画弯弯钩钩多，一笔一笔写清楚，这个字只属于你。」
- 目的 3 层：朴素白描（＋第一人称的情感联结）。
- 拿不准：说文「施身自謂也……从戈从𠄒」——「施身自谓」是用法非字源画面，𠄒（古垂字）无法讲给孩子，字理不写。

## zhe4 这

- meaning：这里（words：这里/这个/这么）
- kaishu：「这，像一条弯弯的小路，一路走过来，这里就到了。」
- 目的 3 层：朴素白描（辶「像小路」视觉明喻；trace/retry 沿用小路意象）。
- sound 用锁定式「这，这里的这。」（zhè/zhèi 两读）。
- 拿不准：shuowen null 后起字，families 无声旁线索（文声旁未学），只做朴素。

## ge4 个

- meaning：一个（words：一个/几个/两个）
- kaishu：「个，是刚学过的人，下面加一竖站到底。以前数竹子，一枝就叫一个。」
- 目的 3 层：构成（人，index 6，真实刚学）＋ 字理（extras 说文条目 via「箇」：「竹枚也。从竹固聲」转写为「以前数竹子，一枝就叫一个」，台词只写现代字形「个」）。
- sound 用锁定式「个，一个的个。」（gè/gě 多音）。
- 拿不准：字头是「箇」，量词义转写是否到位请校对把关。

## men 们

- meaning：他们（words：我们/你们/他们）
- kaishu：「们，左边瘦瘦的，右边一个小方框，轻轻念，跟在我们你们后面。」
- 目的 3 层：朴素白描＋用法（们必须跟在人称后面，教给孩子真实语感）。
- 拿不准：partInfo 标「门 recent:true」但门在 193 序、们在 30 序——门未学，构成与声旁（们与门读音几乎相同）都按「宁可少说」放弃；families「亻族」是部首族非声旁族。这是本批最明显的目的 3 损失点：若未来调整学序让门先行，们课可补「藏着一个门，读音和门很像」。

## 校验与音频

- 逐字 `node scripts/validate.mjs <id> --audio`：10 字全 pass（每字输出「1 个字全部通过（含音频）」）。
- `uv run --with edge-tts python scripts/gen_audio.py de shi4 bu4 le zai4 you3 wo3 zhe4 ge4 men`：70 句一次全部生成，无重试。
- audio_pending：无。
