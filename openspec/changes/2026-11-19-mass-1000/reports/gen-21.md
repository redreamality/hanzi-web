# 第 21 批生成报告（通用课 gen-21）

认领：plan-1000.json 非定制字序第 201 到 210 个，stage 5，共 10 字（pos 221-230）。输入均取自 plan-extras.json 对应条目，pinyin 逐字原样抄录，校验器（含 --audio）10 字全部通过。

## 逐字

### he2c 合（hé）
- meaning：合唱；words：合唱、合作、合上；sound：「合，合唱的合。」（和 he2、河 he2b 已学，同音锁读）
- kaishu：「合，下面有刚学过的口。古人说，合就是把两样东西对到一块儿。」
- 目的 3 层：构成（口 pos 216，序号差 5，真·刚学过）＋字理（《说文》「合口也」——本义合拢，白话为对到一块儿）
- 拿不准：说文「从亼从口」的亼部（上的人+一）没有已学部件对应，上部不提；「对到一块儿」是对「合口也」的宽白话，未做更多引申。

### gei3 给（gěi）
- meaning：给你；words：给你、送给、交给；sound：「给，给你的给。」（多音字 gěi/jǐ，锁 gěi）
- kaishu：「给，右边藏着刚学过的合。很久以前，合就提醒着给的读音呢。」
- 目的 3 层：构成（合 pos 221，序号差 1）＋声旁（说文 via 給「从糸合聲」）
- 拿不准：gěi 与 hé 今音并不像，没用「读音很像」的模板句，只说古时候合提示读音（从糸合聲直证）；糸旁非 recent，未点。

### yuan2b 员（yuán）
- meaning：运动员；words：运动员、队员、演员；sound：「员，运动员的员。」（原 yuan2 已学，同音锁读）
- kaishu：「员，上面有刚学过的口，在这儿它可不是嘴巴，下面像只小贝壳。」
- 目的 3 层：构成（口 pos 216，序号差 7）＋形近不同源提示（说文 via 員「从貝囗聲」——上部实为囗，不是嘴巴的口）＋朴素明喻（贝像小贝壳）
- 拿不准：囗（圆圈，員/圓之初文）才是声旁，但「囗」字未学，声旁层不能点名声旁字；「圆圈」深讲超出 extras 条目的白话安全范围，只保留「在这儿可不是嘴巴」的诚实提醒。

### ge4b 各（gè）
- meaning：各种各样；words：各种、各样、各种各样；sound：「各，各种的各。」（个 ge4 已学，同音锁读）
- kaishu：「各，下面是刚学过的口。古人说，上面像只小脚，走走停停，你有你的走法，我有我的。」
- 目的 3 层：构成（口 pos 216，序号差 8）＋字理（说文「从口、夊。夊者，有行而止之，不相聽也」——上部夂是脚，各行其是不相从）
- 拿不准：「你有你的走法，我有我的」是对「不相聽也」的宽松白话（由脚各走各的引到「各」）；上部夂按明喻「像只小脚」处理，不作字源断言。

### ren4b 认（rèn）
- meaning：认识；words：认识、认字；sound：「认，认识的认。」（任 ren4 已学，同音锁读）
- kaishu：「认，左边一点加个往上挑的小弯，右边一撇一捺叉开脚，合起来就是认。」
- 目的 3 层：朴素（纯白描）
- 拿不准：shuowen 为 null（后起字，繁体認 的说文线索不在本字条目里），families null 无人声旁线索，人 部件 pos 6 非 recent——三层全部放弃，宁可少说。

### tiao2 条（tiáo）
- meaning：面条；words：面条、枝条；sound：「条。」（无已学同音、非多音）
- kaishu：「条，很久以前说的是树上细细的小树枝。你看，细细长长，多像一根面条呀。」
- 目的 3 层：字理（说文 via 條「小枝也」——本义细枝，面条只作明喻）
- 拿不准：简化字形下部含木，但 partInfo 为空（木 pos 太早，非 recent），未点构成；「攸聲」的声旁在简化字「条」里已不见踪影，未点声旁。

### ping2 平（píng）
- meaning：平地；words：平地、平安；sound：「平。」（无已学同音、非多音）
- kaishu：「平，两笔横画平平的，像一小块平地。古人说，分得匀、不偏不斜，就是平。」
- 目的 3 层：字理（说文「語平舒也。从亏从八。八，分也」——分得匀、不偏不斜）＋朴素白描（两道横画平平的）
- 拿不准：字理按说文「八，分也」的会意读法讲「分得匀」；学界对平另有乐器说，本句不越出说文文本。

### xi4 系（xì）
- meaning：没关系；words：没关系、关系；sound：「系，关系的系。」（多音字 xì/jì，锁 xì）
- kaishu：「系，古人说，系就是把东西拴住绑牢，就像用一根丝线打了个结。」
- 目的 3 层：字理（说文「繋也。从糸丿聲」——本义拴绑，丝线是从糸的明喻）
- 拿不准：words 特意避开「系鞋带」（口语里读 jì，会教错读音），meaning 取孩子天天挂嘴边的「没关系」；「丿聲」的声旁信息与字义无关，未点。

### qi4 气（qì）
- meaning：气球；words：气球、空气、天气；sound：「气。」（七是 qī，调不同不算同音；非多音）
- kaishu：「气，很久以前，人们看天上飘的云气，照着画下来的。你看那几笔，像不像飘起来的样子？」
- 目的 3 层：字理（说文「雲气也。象形」——云气象形，全批最干净的证据）

### nv3 女（nǚ）
- meaning：女孩；words：女孩、女儿；sound：「女。」（无已学同音、非多音）
- kaishu：「女，是个特别老的字，古人照着女子的样子画出来的。写字时两笔要交叉好，才站稳。」
- 目的 3 层：字理（说文「婦人也。象形」——照女子样子画）
- 拿不准：甲骨文女子跪坐交手的字形细节没讲（超出 extras 条目文本，避免演绎），只说「照着女子的样子画出来」；后半句是纯书写白描。
