## D10 shuowen 数据源修复（根因 + 修复）

**根因不是脚本解析错位，是源数据问题**（shuowen.org 导出原始文件，9833 条）：

1. **细（id9111）**：raw 文件本身 wordhead=细、内容是垦的土部条目（耕也。从土豤聲，kěn）。build-shuowen 忠实按键收录 → 细 错挂垦义。垦/墾在源数据无独立条目，9111 即垦的内容错挂字头。
2. **终（id8950）**：同型——wordhead=终、内容是龜部龟名字（龜名。从龜夂聲，tónɡ；段注明言声旁是𠂂、即古文終的交叉引用）。正确条目 終(8546 絿絲也。从糸冬聲) 一直在库。
3. **听（id850）**：条目本身合法（说文确有 读 yǐn「笑皃」的 听，另一个字）；错在 build-extras 直查优先，简体 听(=聽) 被同形字遮蔽。
4. **朝（id4260）**：源数据有朝的条目（旦也。从倝舟聲，陟遙切），但 wordhead 是正篆形「𦩻」，标准字形只出现在 indexes 字段；build-shuowen 只读 wordhead → 漏收。此为「朝缺收」根因。

**修复**：
- `scripts/build-shuowen.mjs`：加 `RAW_BAD_IDS = {9111, 8950}` 跳过表（注释写明根因与正确条目 id），坏条目计数入输出。重跑后 shuowen.json 剔除 细/终 两键，9813 键，其余逐字节不变（脚本按 id 升序确定性生成）。
- `scripts/build-extras.mjs`：MANUAL_SHUOWEN 提升到直查之前（注释写明简体同形异字类），新增 `听: '聽'`（聆也。从耳、㥁，壬聲）、`朝: '𦩻'`（旦也。从倝舟聲，indexes 含朝自证）。
- 重跑后 plan-extras 四条转正：细 via:細（微也。从糸囟聲）、终 via:終（絿絲也。从糸冬聲）、听 manual:聽、朝 manual:𦩻。命中统计 direct 549 / via 295 / ambiguous 9 / manual 31 / null 95 = 979。
- **台词依赖核对**：细/终/听三字台词均为朴素描述，未引用坏条目内容；全量 grep「耕也/龟名/龜名/笑皃/笑貌」在 data/chars/*.json 零命中。朝台词为象形白描，与 null→𦩻 转正无冲突。**本轮无台词因 D10 改动**。
- **随机抽查 N=30**（种子 20261120，抽样清单存档于会话 tmp/sample30.txt）：30/30 字头与释义对应（声旁与读音相合、部首与义类相合、引文出处吻合），未再发现错位。

**简繁同形字排查（D10 延伸）**：后(繼體君也)、几(踞几也)、里(居也) 三字直查命中的都是字形本身的合法说文条目（后-君主义存于皇后、几-案几字形本源、里-居也），台词转写无误，维持；听类遮蔽仅听一例。
