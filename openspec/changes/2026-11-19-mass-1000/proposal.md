# mass-1000：重做 1000 字量产（通用课，979 字）

## Why

2026-11-18 的 996 字量产因质量（目的 2、3 静默出局）被用户撤回（备份 `backup/1000-char`）。2026-11-19 用户下令重做并给出三项流程变更（均用户明示，记录在此防「静默降级」误读）：
1. **不再跑 E2E**（交互引擎不改，存量 e2e 不动；内容质量门禁 = 校验器 + 独立校对，即 spec「批量生成完成标准」本来的两道门）；
2. **每批 10 个字一起跑**（SOP 4.3 的 ≤8 是 e2e 满载约束，e2e 取消后放宽为 10）；
3. **考据不抓 zdic**，改用本地《说文》全量数据（`2026-11_shuowen` 项目，shuowen.org 数据，Apache 2.0）；通用课不画古文字层，说文只进台词，不存在「凭印象画形」风险。

## What Changes

- 量产设施从 `backup/1000-char` 回到主线：generic.js/css（词卡→楷书→笔顺→描红）、main.js 定制/通用分发、home.js 千字首页（index.json 单请求、最近 16 卡 + 即将学）、build-list/build-index/validate/sync-strokes/gen_audio 等脚本；选字器（picker）按撤回决定不回来。
- build-list 新增**家族聚簇**（spec 场景落地）：主族聚簇（部件族>部首族>声旁族）+ 部件链随块拉前 + 排序自检断言（部件序 + 主族跨度 ≤1 阶段；放不进的成员显式 defer 报告）。
- 新增数据管线：`shuowen.json`（9833 条说文索引）→ `plan-extras.json`（每通用字：部件近邻、家族、说文条目/简繁解析结果）——生成 agent 的字理输入。
- 979 个通用字（1000 − 21 定制）由 workflow 生成：**每 agent 10 字**（同族相邻切块），98 个生成 agent + 20 个独立校对 agent（每 50 字一个，怀疑复核、直接改、复验）。台词按 SOP 4.4 操作化目的 3：构成关系（部件刚学过时）、声旁点题（形声字）、说文一行字理（有据时；后起字只讲形声或朴素，不虚构）。
- 验收 = `node scripts/validate.mjs`（全量，含 --audio）全绿 + 校对轮完成；不是文件生成。

## Impact

- specs 无增量：本 change 是既有 Requirement（一千字可学、通用课动线、内容质量底线、家族聚簇、字源演变）的执行；家族聚簇场景首次由脚本断言落地。
- 体验面：首页改千字形态（阶段化展示）；21 定制字保持手绘「惊艳」基准不动。
- 音频新增 ~979 组。
- 风险：说文条目为繁体字头（们→們）——台词讲家系不造字源；edge-tts 量产限流——音频允许事后补跑，校验器 --audio 收口。
