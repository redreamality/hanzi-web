# 认字课程（目的 1）

## Purpose

让 3-8 岁孩子有趣地认识并记忆汉字。孩子不识字、自己在平板上操作，全部引导靠声音，动线极简，不依赖任何文字说明。

## Requirements

### Requirement: 一千个生活常用字全部可学

字表取自字频排名的 1000 个生活常用字（顺序规则见 `hanzi-network` spec）。每个字都必须（MUST）有可玩的课。

#### Scenario: 访问字表中任意一字

- WHEN 通过 `?c=<id>` 访问 plan 中任一已学序内的字
- THEN 进入该字的定制课或通用课，不出现空白页或报错

#### Scenario: 未知字或无参数

- WHEN 访问不带 `?c` 的地址，或 id 不在 plan 里
- THEN 落到首页，不报错

### Requirement: 通用课动线

无定制画面的字必须（MUST）走通用课：**词卡（词 + 读音）→ 楷书成形 → 笔顺演示 → 手指描红 → 完成反馈**，按此顺序推进，全程旁白引导。

#### Scenario: 描红偏离

- WHEN 手势明显偏离当前笔画
- THEN 播放 retry 旁白鼓励重来，不惩罚、不扣分、不打断离开的出口

#### Scenario: 完成一课

- WHEN 孩子写完最后一个笔画
- THEN 播放「你会写X啦」收尾旁白，进度记录该字（见 `progress-parent` spec），回首页后下一课字卡亮起

### Requirement: 定制课是「惊艳」基准

日月木人 4 个手绘水墨定制课（字形变形动画、组字交互）必须（MUST）保持现状水准，作为整个产品体验的基准；不得为了与通用课统一而降级它们。

#### Scenario: 不得降级

- WHEN 任何改动涉及定制课（日月木人）
- THEN 改动后的体验不得低于现状，且 change 中必须说明理由

### Requirement: 内容质量底线

批量生成或人工撰写的课程数据必须（MUST）满足：

- `pinyin` 与字表完全一致（校验器机械比对）；多音字的 `sound` 台词用能锁定该读音的词（如 地 di4 →「地，土地的地。」）。
- `meaning`、`words` 是孩子生活中真实、常用、具体的词，优先看得见摸得着的（大→大山，不选「广大」）。
- 台词短句口语、面向 3-8 岁；句中不出现英文字母和数字；每句不超过 50 字；同批句式要有变化。
- 不编造字源、不编造笔画说法；形象描述拿不准就写朴素版本。
- 每字旁白音频（edge-tts 预生成）与台词一一对应。

#### Scenario: 批量生成完成标准

- WHEN 用 workflow / subagent 批量生成课程数据
- THEN 必须通过程序化校验器（schema、读音一致性、音频齐全；随重做的 change 引入）并经独立校对一轮，才算完成；只写完文件不算

### Requirement: 动力来自内容，不来自成瘾机制

产品必须（MUST）不设积分、排行、每日任务、限时。

#### Scenario: 完成反馈

- WHEN 孩子完成一课或学会一字
- THEN 反馈是内容性的（旁白肯定、首页盖「会」印），不出现任何数值、等级或收集奖励
