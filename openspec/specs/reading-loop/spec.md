# 阅读闭环（目的 2）

## Purpose

培养阅读兴趣：孩子在小故事里见到并复习学过的字，点故事里的字能回到它的课。**当前未实现**（见 `project.md` 实现状态对账），本 spec 是约束性合同，约束将来如何把它做出来。

## Requirements

### Requirement: 故事只用已学字

每篇故事按学习阶段生成，正文出现的汉字必须（MUST）是该阶段及之前已学字的子集。用字范围由脚本硬校验，违例即拒收，不允许「差一个字」的通融。

#### Scenario: 越界用字

- WHEN 一篇待入库的故事正文含有该阶段未学的字
- THEN 校验失败，该故事不得入库，需改写或换字后重新校验

#### Scenario: 标点与数字

- WHEN 故事包含标点或非汉字字符
- THEN 校验器按白名单放行（常用中文标点），其余拒绝

### Requirement: 点字回课

阅读中任何一个字都必须（MUST）可以点。

#### Scenario: 点字跳转

- WHEN 孩子点故事正文中的某个字
- THEN 跳到该字的课（或针对已学字的复习动线），从课里返回时回到故事原来的位置

### Requirement: 朗读与节奏

- 每篇故事的朗读必须（MUST）用 edge-tts 预生成，不实时合成。
- 必须同时支持整篇播放和逐句点读；句子要短，配图延续水墨淡彩风格。

#### Scenario: 整篇播放

- WHEN 孩子进入故事页
- THEN 可以只靠听完成整篇阅读，不需要识字

### Requirement: 生成与入库流程

故事必须（MUST）在开发时按学习阶段批量预生成，流程为：生成 → 独立审校 → 程序化校验（用字范围、句长、年龄适宜）→ 人工过目 → 入库。上线后页面不做任何实时 AI 生成。

#### Scenario: 批量生成任务书

- WHEN 用 workflow / subagent 批量生成故事
- THEN 任务书必须引用本 spec 的 Requirement，把「只用已学字」作为硬约束传入，完成标准是校验脚本通过而非文件存在
