# 汉字网络（目的 3）

## Purpose

把汉字连成系统网络，知其然知其所以然：部首归类、声旁家族、字源演变、组字拆字。当前只在排序层面落地（见 `project.md` 对账表）；呈现层的场景是约束性合同。

## Requirements

### Requirement: 学习顺序体现结构

字表 = 字频选 1000 个生活常用字 + 拆字依赖排序：每个合体字必须（MUST）排在它全部部件之后，整体分阶段（字表数据文件随重做的 change 落盘）。日月木人 4 个定制课打头。

#### Scenario: 字表更新时自检

- WHEN 生成或更新字表顺序
- THEN 脚本断言每个合体字的全部部件的序号都小于本字序号，违例即失败

### Requirement: 组字拆字关系可见

- 定制课示范基准：日 + 月 → 明（天空亮起）、木 → 林 → 森、人靠木 → 休、青加氵/日 → 清/晴。
- 通用课层面：讲到合体字、且其部件刚在前面学过、构成关系有把握时，旁白必须（MUST）至少点出一层构成关系（「X 里有刚学过的 Y」）；拿不准就不提，不硬编。

#### Scenario: 有把握时点出构成

- WHEN 通用课的字的某部件在近几个阶段内刚学过，且构成关系明确
- THEN 该字的旁白台词中有一句点出这个构成关系

#### Scenario: 拿不准时保持朴素

- WHEN 构成关系或字源没有可靠依据
- THEN 台词不提构成和字源，只做朴素描述（宁可少说，不可说错）

### Requirement: 部首归类与声旁家族（目标态）

家长端的全字表必须（MUST）支持按部首、按声旁分组浏览；点一个部件或声旁，能看到它参与构成的那些字，以及这些字分别在第几阶段学。

#### Scenario: 按声旁浏览

- WHEN 家长在字表中选「青」的声旁家族
- THEN 看到 清、晴、请、情 等字 grouped 在一起，标注各自学习阶段

### Requirement: 字源演变（目标态）

字源动画（实物 → 甲骨文 → 楷书）必须（MUST）只在有可靠来源时呈现：授权清楚的开源古文字字形，或有权威出处的字源说明。无来源就不呈现该层，禁止编造或臆测演变。

#### Scenario: 无来源的字

- WHEN 某字找不到可靠古文字形来源
- THEN 该字的课不出现字源演变环节，直接走通用动线
